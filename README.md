# Satyam With Me Cloud - Complete
Run: npm install && npm start
Open http://localhost:3000

Features: registration, email/demo OTP, login/logout, forgot password, password reset OTP, profile API/photo upload, 5GB quota, uploads/download/delete, folders API, file search.
For real OTP, copy .env.example to .env and configure SMTP_HOST, SMTP_USER, SMTP_PASS, SMTP_FROM.
Never share SMTP passwords publicly.
